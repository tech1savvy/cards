# SSL/TLS

- **TLS** stands for ==Transport Layer Security==.
- **SSL** stands for ==Secure Sockets Layer==.

- TLS is the ==1;;successor== to SSL, which is now ==1;;deprecated==.

- TLS provides ==1;;encryption==, ==1;;integrity==, and ==1;;authentication== for data in transit.

- On the web, HTTP secured by TLS is called ==HTTPS==.
