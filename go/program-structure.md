# Entry point

What is the entry point for a Go program?

***

`func main()` is the entry point.

# Package main

What does `package main` mean in Go?

***

It means this is a standalone program to be compiled and run, rather than a library to be imported.

# Imports

How do you import packages in Go?

***

Single import:
```go
import "fmt"
```

Grouped imports:
```go
import (
    "fmt"
    "errors"
)
```

# Comments

How do you write single-line and multi-line comments in Go?

***

Single-line: `// comment`
Multi-line: `/* comment */`
