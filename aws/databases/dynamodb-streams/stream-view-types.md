# What Stream View Types does DynamoDB Streams support?

---

Defines what data is captured.

| View Type        | Data Captured      |
| ---------------- | ------------------ |
| Keys Only        | Primary key only   |
| New Image        | Item after change  |
| Old Image        | Item before change |
| New + Old Images | Both versions      |
