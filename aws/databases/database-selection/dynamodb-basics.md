# What are the core concepts of DynamoDB?

---

Fully managed **NoSQL** key-value database with **millisecond** response times at any scale.

**Table**

- Collection of data

**Item**

- Record in a table

**Attribute**

- Data field within an item

**Primary Key**

- Designated attribute that uniquely identifies each item
