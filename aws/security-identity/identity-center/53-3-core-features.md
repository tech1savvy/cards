# What are the core features of IAM Identity Center?

---

Centralized Identity Management

- create users/groups in AWS
- or connect external identity providers.

Supported identity sources:

- Okta
- Azure AD
- Microsoft Active Directory.

Single Credentials

- one login for all AWS accounts and apps.

AWS Access Portal

- web dashboard showing all available accounts and apps
- one-click access to AWS console.
