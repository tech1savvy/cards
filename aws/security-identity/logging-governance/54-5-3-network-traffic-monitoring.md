# How does network traffic monitoring work with VPC Flow Logs?

---

## VPC Flow Logs

Captures **IP traffic metadata**.

Shows:

- source IP
- destination IP
- port
- protocol
- accept/deny status.

Use cases:

- troubleshoot security groups
- analyze network traffic patterns.

Important:
Collected **outside the traffic path**, so no performance impact.
