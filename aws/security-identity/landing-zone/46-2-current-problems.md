# What are the current problems with a single-account AWS setup?

---

Root User Usage

- lead engineer logs in using root credentials.

Weak Access Control

- IAM users manually created
- permissions loosely managed.

Billing Chaos

- cost tracking relies on inconsistent tags.

Manual Onboarding

- new developers added manually.

Operational Risk

- wrong stack changes already occurred.
