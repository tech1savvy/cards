# What are the key benefits of Infrastructure as Code?

---

Standardization

- eliminates manual configuration mistakes.

Repeatability

- deploy the same architecture across regions or accounts.

Version Control

- templates stored in Git
- supports code reviews and rollback.

Dependency Management

- CloudFormation automatically creates resources in correct order.

Example:
VPC → Subnet → EC2.
