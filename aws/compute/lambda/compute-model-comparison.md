# How do EC2, containers, and Lambda compare as compute models?

---

| Service           | Model                 | Ops Effort | Typical Use                         |
| ----------------- | --------------------- | ---------- | ----------------------------------- |
| Lambda            | Serverless            | Minimal    | Short tasks, event-driven workloads |
| EC2               | Virtual machines      | High       | Full control, legacy apps           |
| Fargate           | Serverless containers | Low        | Containerized microservices         |
| Elastic Beanstalk | PaaS                  | Medium     | Simplified app deployment           |
