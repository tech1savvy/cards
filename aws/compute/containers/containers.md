# Containers

A container is a ==standardized unit that packages code and all its dependencies==.

- Containers provide ==isolation== (their own independent environment).
- Containers provide ==standardization== (run reliably on any platform).
- Docker is a popular *container runtime*.

## How do containers compare to VMs?
| Feature      | Containers                   | VMs               |
| ------------ | ---------------------------- | ----------------- |
| OS/Kernel    | Share host's OS and kernel   | Own guest OS      |
| Weight       | Lightweight (MBs)            | Heavyweight (GBs) |
| Startup Time | Almost instant (seconds)     | Minutes (full boot) |
