# Amazon S3

- S3 stands for ==Simple Storage Service==.

- Amazon S3 is *object* storage with usage-based billing, **replicated** across *multiple Availability Zones*. 
- Best for static assets and backups.

## Properties
- S3 stores data as ==1;;objects== within ==1;;buckets==.

- An **object** consists of a *file* with ==1;;key== as its *unique identifier* and optionally any ==2;;metadata== that describes that file.

- Individual S3 objects can be up to ==1;;5 TB==, with an ==1;;unlimited== number of objects.

- URL structure of any S3 bucket :: `http://[bucket-name].s3.amazonaws.com/[object-key]`

- An S3 bucket's geographical location is determined by the *Region* you choose. Data is *redundantly stored across multiple facilities within that Region*.

- Everything in S3 is ==private== by default. 

- **Block Public Access** is a bucket-level safety setting to prevent accidental exposure. IAM Policies and S3 Bucket Policies control permissions.

## Features

### Lifecycle Management

S3 Lifecycle Management automates object storage management through two actions
***
- *Transition* moves objects to cheaper storage classes over time.
	- Example: Standard → Standard-IA → Glacier.
- *Expiration*: Automatically delete objects after a defined period.
	- Example: Delete logs after 365 days.

### Encryption

- Encryption **At Rest** in S3:
	1. Server-side: data is encrypted by ==1;;AWS==.
	2. Client-side: data is encrypted by ==1;;you before upload==.

- Encryption **In Transit** in S3: Protects data during transfer using ==SSL/TLS== protocols.

### Versioning

S3 Versining allows you to keep *multiple versions* of an *object* in the *same bucket*.
- Guards against accidental deletions or overwrites.
- Deleting an object adds a  ==delete marker instead of removing it permanently.==

### Cross-Region Replication

What is Cross-Region Replication (CRR) in S3?
***
==Cross-Region Replication(CRR)== in S3 automatically *copies* objects to a bucket in another **AWS Region**.

- Replicates:
	- objects
	- metadata
	- tags

- Use cases:
	- regulatory compliance
	- geographic redundancy
	- lower latency for global users
	- cross-account data protection
