# What are the key features of Amazon SNS?

---

**Message Filtering**

- Route messages to specific subscribers
- Uses message attributes or payload filtering

**Security**

- Encryption in transit (default)
- Server-side encryption (SSE)
- Resource policies for `Publish` / `Subscribe`

**Durability**

- Messages replicated across multiple AZs
