# What are the key features of Amazon QuickSight?

---

**SPICE Engine**

- In-memory analytics engine
- Fast query performance
- Supports many concurrent users

**Natural Language Queries (QuickSight Q)**
Users can query data in plain English.

Example:

Top 10 dishes viewed last week

**ML Insights**

- Detect anomalies
- Identify trends automatically

**Pay-per-Session Pricing**

- Charges based on actual dashboard usage
