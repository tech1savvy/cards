# What are the stages of the data analytics lifecycle?

---

Typical pipeline stages:

1. **Storage**
   - Data lake in **Amazon S3**

2. **Ingestion**
   - Collect data from applications or streams

3. **Processing / Query**
   - Analyze data using serverless tools

4. **Visualization**
   - Dashboards and reports
