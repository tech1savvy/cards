# What are the operational characteristics of the serverless analytics architecture?

---

**Cost**

- Usage-based billing
- No idle infrastructure

**Resilience**

- S3 durability (11 nines)
- Cross-region backup

**Maintenance**

- Fully serverless
- No server management

**Flexibility**

- New analytics tools can read data directly from S3
