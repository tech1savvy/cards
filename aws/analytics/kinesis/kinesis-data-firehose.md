# What is Kinesis Data Firehose and why was it selected?

---

Characteristics:

- Fully managed
- Automatic scaling
- Delivers data to storage (e.g., S3)
- Uses batching → slightly higher latency

Decision: **Selected**

Reason:

- Minimal operational effort
- No custom ingestion code required
- Acceptable latency for analytics workloads
