# What is the difference between Terraform Cloud and Terraform Enterprise?

---

| Aspect              | Terraform Cloud                                                          | Terraform Enterprise                                                                              |
| ------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| **Hosting**         | SaaS — hosted and maintained by HashiCorp                                | Self-hosted — deployed in your own infrastructure                                                 |
| **Best for**        | Small to medium teams                                                    | Large organizations needing full control                                                          |
| **Key features**    | Remote state, workspaces, VCS integration, policy enforcement            | All Cloud features + private module registries, granular access controls, advanced security       |
| **On-prem support** | Limited                                                                  | Full on-premises deployment                                                                       |
| **Control**         | Managed by HashiCorp                                                     | Full organizational control over infrastructure and data                                          |
