# What is Terraform Cloud for Business?

---

Terraform Cloud for Business is a paid tier of Terraform Cloud offering additional features for larger teams:

- **Single sign-on (SSO)** — integrate with enterprise identity providers
- **Audit logging** — track who made what changes
- **On-premises resource management** — manage on-prem infrastructure from the cloud
- Same hosted environment as standard Terraform Cloud (app.terraform.io)
