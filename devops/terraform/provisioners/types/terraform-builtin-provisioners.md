# What are the built-in provisioners available in Terraform?

---

- `file` — copies files/directories to the resource
- `local-exec` — runs commands on the machine running Terraform
- `remote-exec` — runs commands on the remote resource
- `chef` — bootstraps resources using Chef
- `puppet` — bootstraps resources using Puppet
- `salt-masterless` — bootstraps resources using Salt (masterless)
- `habitat` — bootstraps resources using Habitat
