# What are the key use cases of Terraform?

---

- **Heroku App Setup** — codify Heroku app config, DNS, CDN
- **Self-Service Clusters** — product teams manage their own infrastructure via shared Terraform configs
- **Disposable Environments** — quickly create/destroy staging, QA, dev environments matching production
- **Resource Schedulers** — provision into Borg, Mesos, Kubernetes alongside physical infrastructure
- **Software Demos** — provision and bootstrap demos on cloud providers for end users
- **Multi-Tier Applications** — manage complex, layered architectures
