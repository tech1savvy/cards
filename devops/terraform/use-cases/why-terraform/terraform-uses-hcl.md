# Why does Terraform use HCL (HashiCorp Configuration Language)?

---

HCL is a declarative language designed to be human-readable and easy to learn. You describe the desired end state of your infrastructure and Terraform figures out the steps to get there. Its straightforward syntax lowers the barrier to entry compared to general-purpose programming languages while still supporting variables, conditionals, and loops.
