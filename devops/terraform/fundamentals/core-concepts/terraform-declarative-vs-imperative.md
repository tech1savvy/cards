# What is the difference between declarative and imperative IaC?

---

- **Declarative** (Terraform) — defines the *desired end-state*; the tool figures out how to achieve it. Less complex, more reliable for managing state over time.
- **Imperative** (shell scripts) — provides explicit step-by-step commands that must be executed in order to reach the desired state.
