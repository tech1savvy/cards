# What is Infrastructure as Code (IaC) and what are its main benefits?

---

IaC is managing and provisioning infrastructure through machine-readable configuration files rather than manual processes.

- **Speed & Efficiency** — automation increases deployment speed
- **Consistency** — identical environments across dev, staging, production
- **Scalability** — infrastructure can be replicated easily
- **Version Control** — track changes, collaborate effectively, reduce human error
