# How do you use Terraform with version control systems like Git?

---

- **Repository setup** — create a Git repository to store Terraform configurations
- **Commit and push** — regularly commit and push changes
- **Branching** — use branches for different environments or features
- **Pull requests** — use PRs for code review and collaboration before merging
- **Tags** — tag releases for versioning and reproducibility
- **CI/CD integration** — integrate with CI/CD pipelines for automated testing and deployment
